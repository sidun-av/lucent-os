# Third-party components of the Lucent look

Everything below may be redistributed under its license. Lucent's own design
files are Apache-2.0 like the rest of the repository unless noted.

## Installed from packages at image build time (`build_files/design.sh`)

| Component | Used for | Source | License |
| --- | --- | --- | --- |
| Papirus icon theme (`papirus-icon-theme`) | every icon Lucent doesn't draw: Lucent inherits Papirus-Light, Lucent-Dark inherits Papirus-Dark | Fedora repositories; upstream github.com/PapirusDevelopmentTeam/papirus-icon-theme | GPL-3.0-only (some icons CC-BY-SA-4.0, LGPL-3.0-or-later) |
| KDE-Rounded-Corners (`kwin-effect-roundcorners`) | KWin effect: 14 px window corners and the 1 px outline | COPR `matinlotfali/KDE-Rounded-Corners` (the author's own builds); upstream github.com/matinlotfali/KDE-Rounded-Corners | GPL-3.0 |
| Plymouth spinner frames (`plymouth-theme-spinner`) | throbber of the `lucent` boot splash (copied next to Lucent's logo) | Fedora repositories | GPL-2.0-or-later |
| Inter (`rsms-inter-fonts`) | UI font | Fedora repositories; upstream rsms.me/inter | OFL-1.1 |
| Breeze widget style, cursors, KDE Plasma | widget style (driven by the Lucent colour schemes), cursors, the Plasma theme parts Lucent doesn't override | Fedora Kinoite base image | LGPL-2.1-or-later / GPL-2.0-or-later |

## In this repository

| Path | What | License |
| --- | --- | --- |
| `system_files/usr/share/plasma/plasmoids/org.lucent.launcher/` | full-screen launcher; written for Lucent, uses Plasma's kicker backend (`org.kde.plasma.private.kicker`) | GPL-2.0-or-later |
| `system_files/usr/share/kwin/tabbox/org.lucent.switcher/` | Alt+Tab switcher, derived from KWin's Thumbnail Grid (© Chris Holland, Nate Graham) | GPL-2.0-or-later |
| `system_files/usr/share/plasma/plasmoids/org.lucent.search/` | taskbar search field | Apache-2.0 |
| `system_files/usr/share/plasma/desktoptheme/lucent*` | Plasma theme (taskbar, popups, task buttons), generated by `design/gen_plasma_theme.py`; files it doesn't contain fall back to Breeze | Apache-2.0 |
| `system_files/usr/share/aurorae/themes/Lucent*` | window decoration, generated by `design/gen_aurorae.py` | Apache-2.0 |
| `system_files/usr/share/icons/Lucent*` | app/folder icons and logo, exported from the mockups' original drawings (`docs/mockups/lucent.js`) by `design/gen_icons.py` | Apache-2.0 |
| `system_files/usr/share/wallpapers/Lucent/` | "Lucent Flow" wallpaper, rendered from the mockups by `design/render_wallpaper.py` | Apache-2.0 |
| `system_files/usr/share/plymouth/themes/lucent/` | boot splash config and logo (spinner frames added at build, see above) | Apache-2.0 |
| `system_files/usr/share/color-schemes/Lucent*.colors` | colour schemes from the mockup tokens (`design/gen_colors.py`) | Apache-2.0 |

App icons in the Lucent theme replace the generic icons of some third-party
apps (Firefox, ONLYOFFICE, GIMP, ...) with Lucent-style tiles, the same way
Papirus does; they are original drawings, not the apps' logos.
