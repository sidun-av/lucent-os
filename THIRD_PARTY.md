Everything below may be redistributed under its license. Lucent's own design
files are Apache-2.0 like the rest of the repository unless noted.

## Installed from packages at image build time (`build_files/design.sh`)

| Component | Used for | Source | License |
| --- | --- | --- | --- |
| Papirus icon themes (`papirus-icon-theme`, `-light`, `-dark`) | every icon Lucent doesn't draw: Lucent inherits Papirus-Light, Lucent-Dark inherits Papirus-Dark | Fedora repositories; upstream github.com/PapirusDevelopmentTeam/papirus-icon-theme | GPL-3.0-only (some icons CC-BY-SA-4.0, LGPL-3.0-or-later) |
| KDE-Rounded-Corners (`kwin-effect-roundcorners`) | KWin effect: 14 px window corners and the 1 px outline | COPR `matinlotfali/KDE-Rounded-Corners` (the author's own builds); upstream github.com/matinlotfali/KDE-Rounded-Corners | GPL-3.0 |
| Plymouth spinner frames (`plymouth-theme-spinner`) | throbber of the `lucent` boot splash (copied next to Lucent's logo) | Fedora repositories | GPL-2.0-or-later |
| Inter (`rsms-inter-fonts`) | UI font | Fedora repositories; upstream rsms.me/inter | OFL-1.1 |
| Kvantum (`kvantum`) | SVG widget-style engine for Qt apps; draws Lucent's theme (`/usr/share/Kvantum/Lucent`) under Lucent's style plugin | Fedora repositories; upstream github.com/tsujan/Kvantum | GPL-3.0-or-later |
| SDDM (`sddm`, `sddm-wayland-plasma`) | login screen (display manager) running Lucent's `lucent` theme on KWin | Fedora repositories; upstream github.com/sddm/sddm | GPL-2.0-or-later (sddm-wayland-plasma: from plasma-workspace, GPL-2.0-or-later) |
| Breeze cursors, KDE Plasma | cursors, the Plasma theme parts Lucent doesn't override; Breeze stays installed as the fallback widget style | Fedora Kinoite base image | LGPL-2.1-or-later / GPL-2.0-or-later |

| `build_files/lucent-style/` | Qt style plugin `lucent` / `lucent-dark`: a QProxyStyle over Kvantum (Dolphin path bar field and position, flat toolbar actions, free-space line), built at image build time | Apache-2.0 |
| `system_files/usr/share/sddm/themes/lucent/` | SDDM login theme, written for Lucent | Apache-2.0 |
| `system_files/usr/share/lucent/design/lockscreen/LockScreenUi.qml` | lock screen UI, replaces Plasma's at build time; derived from Plasma's `LockScreenUi.qml` (© Aleix Pol Gonzalez, Kristen McWilliam) for the authentication flow | GPL-2.0-or-later |
| `system_files/usr/share/color-schemes/Lucent*.colors` | colour schemes from the mockup tokens (`design/gen_colors.py`) | Apache-2.0 |

App icons in the Lucent theme replace the generic icons of some third-party
apps (Firefox, ONLYOFFICE, GIMP, ...) with Lucent-style tiles, the same way
Papirus does; they are original drawings, not the apps' logos.
