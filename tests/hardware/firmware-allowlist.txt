# Firmware files that drivers of the core classes (Wi-Fi, Ethernet,
# Bluetooth, audio, GPU) may request but that are NOT in the image, and why.
# The hardware audit (hw_audit.py, CI: hardware-audit.yml) fails when a core
# firmware file is missing and is not listed here, or is listed as "absent"
# but a Fedora package ships it after all.
#
# Format: <glob on the name `modinfo -F firmware` prints> <kind> <reason>
#   absent    no Fedora 45 package ships it (checked with dnf repoquery on
#             the full Fedora + updates file lists, 2026-11-09)
#   excluded  Fedora ships it, Lucent leaves it out on purpose
# Versions a driver can do without (it tries several firmware API versions
# and one is installed) are not listed: hw_audit.py's ALTERNATIVES handle them.
